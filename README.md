# Alluvial site redesign

A redesign of alluvial.coach: mockups, a working custom WordPress theme, and a build guide.

- **`GUIDE.md`** — start here. Covers what's on the live site today, what the redesign changes and why, and step-by-step instructions for installing and configuring the theme.
- **`mockups/`** — eight static HTML pages (Home, My Profile, My Philosophy, My Practice, Testimonials, Insights, an article, Contact), sharing one CSS design system. Open `mockups/index.html` in a browser.
- **`theme/alluvial-coach/`** — an installable WordPress theme implementing the mockups, with a Testimonials post type, Customizer-driven homepage hero, and a working contact form.
